# Keitaro Wrapper

Обёртка над API Keitaro на FastAPI.

## О проекте

Приложение позволяет создавать и редактировать рекламные кампании в Keitaro через собственный API и веб-интерфейс.

Проект выполнен в рамках тестового задания на позицию Backend Developer.

## Возможности

### Создание кампании

Приложение позволяет создать кампанию с названием, GEO-кодом страны, доменом, группой, источником трафика и выбранным оффером Keitaro.

Название кампании должно начинаться с test_nasirdinov_.

После создания автоматически создаются два потока:

1. Geo COUNTRY -> Google — принимает пользователей из выбранной страны и перенаправляет их на Google.
2. Offers — содержит выбранный оффер с весом 100%.

### Редактор кампании

Поддерживаются:

- получение потоков из Keitaro;
- добавление офферов;
- удаление офферов;
- восстановление удалённых офферов;
- Pin / Unpin офферов;
- автоматический пересчёт весов;
- публикация изменений в Keitaro;
- отмена неопубликованных изменений;
- синхронизация с Keitaro.

## Синхронизация

Приложение хранит локальное состояние кампаний, потоков и офферов в PostgreSQL.

Если оффер был удалён непосредственно в Keitaro, локальная запись не удаляется, а переводится в статус removed.

Это позволяет сохранить информацию об оффере и восстановить его через wrapper.

## Распределение весов

Вес активных офферов автоматически распределяется между ними.

Закреплённые офферы сохраняют свой вес, а оставшийся процент распределяется между незакреплёнными активными офферами.
